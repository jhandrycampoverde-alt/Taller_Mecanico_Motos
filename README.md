# Base de datos: Taller mecánico de motos

Proyecto de fin de la Unidad 1 de Base de datos (Universidad Nacional de Loja).

Sistema de base de datos relacional para gestionar clientes, motos, mecánicos,
órdenes de servicio, servicios, repuestos y proveedores de un taller mecánico de motos.

## Contenido

- `taller_motos.sql`: creación de la base de datos, las 9 tablas y los datos de ejemplo.
- `consultas.sql`: cinco consultas (selección, reunión, diferencia, división y agrupamiento).
- `diagramas/`: diagrama Entidad-Relación y modelo relacional.

## Cómo ejecutarlo

1. Tener MySQL 8.0.16 o superior (o MariaDB) y un cliente como DBeaver o MySQL Workbench.
2. Ejecutar `taller_motos.sql` completo.
3. Ejecutar las consultas de `consultas.sql`.
